# Overview

This portfolio was designed and developed to showcase my technical expertise, professional experience, and software development projects in a modern, interactive, and responsive interface.

The application emphasizes clean UI, smooth animations, excellent user experience, accessibility, and high performance across desktop, tablet, and mobile devices.

# Getting Started

## Clone the Repository

```bash
git clone https://github.com/mikeisresilient/mike-is-resilient.git
```

---

## Navigate into the Project

```bash
cd mike-is-resilient
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Create Production Build

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```
